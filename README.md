# new-venture

Venture-studio working repo: research → validation kit → iOS MVP for one niche, paid iOS app.

| Path | What it is |
| --- | --- |
| `research/market-research.md` | Phase 1 market research: 25+ niches scored, top-3 deep dives, offers, hypotheses, MVPs |
| `research/raw/` | Raw scout findings behind the report (evidence, quotes, source URLs) |
| `engine/` | Dependency-free JS rules engine + golden test vectors (Phase 2) |
| `landing/` | Self-contained landing page that delivers the aha moment in-browser (Phase 2) |
| `validation/` | Week-by-week validation plan, channel posts, interview script, SOPs, risk memo (Phase 2) |
| `ios/` | SwiftUI MVP, local Swift package port of the engine, XcodeGen project (Phase 3) |

Status is tracked in `research/market-research.md` and in the final report on the session branch.
